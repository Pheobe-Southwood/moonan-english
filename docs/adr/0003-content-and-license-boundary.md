# ADR-0003：原创代码与题库内容分离授权

- 状态：已接受
- 日期：2026-09-09

## 背景

应用代码需要公开发布，而内置真题、图表文字描述和项目评分细则具有独立的内容权利与使用风险。

## 决策

原创源代码采用 AGPL-3.0-only；题库、题文整理、图表描述和评分细则不宣称获得该代码许可。仓库不收录原始资料压缩包、临时图片或来源链接，题库以应用所需的核验后结构化内容发布。`NOTICE` 和 README 明确这一边界及发布者/使用者的内容责任。

## 后果

代码贡献者可以按 AGPL 条款使用和修改原创代码，但不能仅凭代码许可证推断题库内容可自由再发布。后续加入第三方资源时必须单独检查其许可，不得把内容文件自动标为 AGPL。

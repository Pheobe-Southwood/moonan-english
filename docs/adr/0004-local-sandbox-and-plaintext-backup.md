# ADR-0004：仅使用应用沙箱并提供明文备份

- 状态：已接受
- 日期：2026-09-09

## 背景

应用只有一名用户，数据包括答案、图片、提示词、原始 AI 响应和 API 密钥；用户明确接受本机优先和明文备份的取舍。

## 决策

数据仅保存在 Android 应用私有目录，不增加账号、云同步、服务端数据库、Keystore、数据库加密或应用锁。用户可主动导出包含全部数据的明文 ZIP；导出前必须显示不可跳过的密钥泄露警告，恢复前校验清单与哈希并采用原子替换。

## 后果

设备系统锁和备份文件的保管责任由用户承担。实现更简单且可迁移，但明文备份被复制后即可暴露密钥；应用必须在界面、README 和恢复流程中反复说明这一风险，并避免自动导出或上传。
